## Process Findings

- **VALIDATE:** A parent can record a submodule commit that exists only locally.
  A working developer checkout can hide this; a clean clone is the necessary release
  gate.
- **FIX:** Copied fixture directories and a Python-invoking Rust harness allowed the two
  language suites to drift.
  Direct pinned assets remove that ambiguity.
- **ADD:** Baseline version and in-progress contract commit need separate status fields.
- **CLARIFY:** Function mapping is supplementary when one shared process-level case is
  the real cross-language counterpart.
- **FIX:** Preserving undiscovered Rust inventory rows hid deleted and renamed tests.
  Cargo’s deduplicated executable list is now authoritative; rustdoc tests receive real
  source identities, and mappings target the current wrappers.
- **FIX:** Preserving undiscovered Python inventory rows also hid renamed and deleted
  tests. Python discovery now treats the AST and shared tryscript directory as one
  authoritative v0.7.3 inventory.
- **GENERALIZE:** A known-divergence ledger should fail in both directions so resolved
  debt cannot remain silently accepted.

These findings should be contributed to the playbook case study and improvement log
after the Flowmark sync is complete, as required by the canonical closure loop.
