## Interaction Findings

### Protected Block Adjacency

CommonMark raw HTML types 1–6 can interrupt lazy list continuation.
Both implementations now isolate an adjacent protected block from preceding parser
content and remove only the bridge’s synthetic boundary during restoration.
This prevents protected source from being merged into, or deleting, the preceding list
paragraph.

### Whole-Document Fixed Points

Three broad reference cases exposed second-pass drift.
The fixes cover Markdown block markers created at semantic line starts, nested quote
conversion in one invocation, ellipsis punctuation boundaries, and the distinction
between Pandoc line blocks and single-column GFM tables.
The semantic, cleanup, and full-typography reference documents now reach exact fixed
points in both ports.

### Angle Comparisons Versus HTML

The first recovered-corpus run failed closed on `<15min`, `<1.5x`, and similar
comparison text in GFM tables.
The angle scanner had accepted any `<...>` run, crossed cells and lines, and allowed the
parser to lose a preservation token.
The shared case `preservation.extension.raw-html.angle-comparisons` now distinguishes
valid HTML tags, declarations, URI/email autolinks, and angle link destinations from
comparison text.

### Prose Pipes Versus GFM Tables

The next corpus run found one Rust-only difference in a multiline code span containing a
TypeScript union pipe.
Rust had treated every prose line containing `|` as table cells, which prevented the
backtick pair from sharing a scan scope.
Rust now activates cell-by-cell scopes only for a recognized GFM header/delimiter
sequence. The shared `preservation.code-span.multiline-containers` case carries the
regression.
