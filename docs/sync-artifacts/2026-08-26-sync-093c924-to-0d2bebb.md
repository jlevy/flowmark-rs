## Senior Review Finding: Sibling Container Identity

The first green Rust implementation keyed display blocks by blockquote depth and content
column.
That was insufficient: sibling list items can have identical depth and column but
must never share an opener and closer.

The scanner now ports the active container-frame identity used by Python.
Each quote or list frame retains its source identity and list content column; lazy
continuations reuse the active frames, while a new sibling marker creates a new
identity. The new shared case `preservation.math.block.sibling-boundaries` applies smart
quotes to intervening prose, so an accidental cross-item protected region is observably
wrong in either language.
This moved a Python-only scanner invariant into the portable end-to-end contract.

  and tryscript layers.

## Complexity and Failure Boundaries

The token representation is always 10 Unicode scalars: start control, eight encoded
big-endian index bytes, and end control.
Region count therefore cannot inflate token width or make wrapping quadratic.
Authored controls are reversibly escaped and retain one logical source column.

Restoration rejects malformed escapes and tokens, unknown indexes, side-table drift,
missing/duplicate/reordered tokens, and block tokens that lose their structural LF.
Invalid input bytes return the shared `Error: input is not valid UTF-8` message with
exit status 2 before any in-place write occurs.
