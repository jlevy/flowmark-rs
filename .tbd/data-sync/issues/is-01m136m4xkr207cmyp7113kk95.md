Found by a full Rust-vs-Python output sweep of every shipped document in six modes
(9,204 comparisons). Everything else that differs is either an already-ledgered
CommonMark divergence or a `deferred` case; these two documents are the only ones outside
both sets, and both differ only in `--width 40`.

## 1. A period escape that postprocessing removes is still measured

`postprocess_period_escapes` (COMRAK-WORKAROUND11) drops an unnecessary `\.` *after*
rendering, so wrapping measured the line with the backslash still present. When that one
column decides the fit, Rust breaks a token earlier than Python:

    $ sed -n 228p tests/tryscript/fixtures/content/parity-corner-cases.md |
        flowmark --width 40 -

    rust:    \' \( \) \* \+ \, \- . \/ \: \; \< \=
    python:  \' \( \) \* \+ \, \- . \/ \: \; \< \= \>

Rust's second line is 37 columns where 40 were available; Python's is exactly 40.
Substituting `\,` for the `\.` — an escape nothing removes — makes both ports agree
exactly, which isolates the cause to the post-render removal rather than to the wrapper.

## 2. Authored preservation sentinels measure differently

`tests/parity_corpus/cases/preservation/math-inline/sentinel-collision/input.md` holds
authored `U+F0000`-`U+F0002` scalars, which the bridge escapes to two-scalar sequences and
restores after rendering. At width 40 Python breaks one word earlier than Rust, so the two
ports assign different widths to the escaped form. `authored_marker_escapes_retain_one
_column_each` pins the Rust side; nothing pins the pair.

## Why it was not caught

Both documents have shared conformance cases, but each case pins one CLI invocation and
neither uses a narrow width. The mode matrix only exists in the idempotence gate, which
asks whether each port is self-consistent, not whether the two agree. Nothing today
compares the ports across the mode matrix.

## Ask

Measure the string wrapping will actually emit: either remove the period escape before
wrapping rather than after, or have the width function discount placeholder scalars that
postprocessing will rewrite. Agree the sentinel width upstream first, per convention. Then
add shared cases at a narrow width for both shapes — and consider a cross-port sweep over
the mode matrix as a standing gate, since that is the layer that has no coverage.

Not a PR #81 regression: v0.3.2 shows the same two differences.

## Notes

Final release-audit disposition 2026-09-04: the period-escape defect was fixed on main by d6bd277 following 29c9594. The sentinel-width defect belonged to Python current and is fixed by fm-0dmt: canonical authored-marker escapes now measure at logical width and the shared width-40 case passes in both ports. Full four-way comparison of Python 0.7.3, Python current, Rust 0.3.2, and Rust current over 1,677 tracked UTF-8 Markdown documents in six modes reports zero new current cross-port differences.
