## [0.2.0] (parity: flowmark-py 0.6.4)

First formal release. Rust port with full behavioral parity to Python flowmark v0.6.4.

- Identical CLI interface and output to the Python version
- Available as both a library crate and CLI binary
- CI pipeline with coverage, semver-checks, and dependency auditing
- Automated crates.io publishing via trusted publishing (OIDC)
